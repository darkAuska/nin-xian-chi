# 《您先吃》

独立的单场景网页概率博弈游戏原型，使用 TypeScript、Phaser 3 和 Vite。

## 本地运行

```bash
npm install
npm run dev
```

默认地址：`http://127.0.0.1:3001/`

## 当前玩法

1. 记住本轮普通甜椒和超级无敌辣椒的数量。
2. 洗牌后形成隐藏的固定队列，服务员每次只端上一盆。
3. 决定前可以使用道具：“牙签”查看当前盆，“公筷”交换当前盆与下一盆，“打包盒”无伤打包当前盆，“魔鬼辣椒油”强化下一颗被吃掉的超级辣椒。
4. 决定“我先吃”或“您先吃”，不能任意挑选后面的盆。
5. 当前盆结算后，服务员才会端上队列中的下一盆。
6. 自己吃到普通甜椒可继续行动；吃到超级无敌辣椒会失去一杯牛奶。

领导会按公开概率和自己用牙签获得的私有信息使用道具，不会读取未知食物的真实身份。

## 操作与表现

- 鼠标与触摸均可操作；建议手机横屏游玩，竖屏会显示旋转提示。
- 每次行动可先点道具，再点“我先吃”或“您先吃”；动画播放期间会锁定重复输入。
- 对局中可随时“立即重开”，结算后可“一键再吃一桌”。
- 餐盖、吞咽、喷火、喝奶和道具声音在首次开始后启用；辣椒包含纸片火焰、桌面震动和逐杯牛奶反馈。
